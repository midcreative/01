## Context (背景情境)

目前在 `index.php` 裡，分類統計區塊外層使用的 Tailwind 類別是 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4`。這表示在沒有指定斷點的預設情況下（通常是手機螢幕），它會顯示成單一欄位。為了讓畫面更緊湊並減少手機使用者的滑動長度，我們需要將預設改為兩欄。

## Goals / Non-Goals (目標與非目標)

**Goals (目標):**
- 更改分類統計區塊在手機端的網格列數為兩欄。
- 確保內部元素（字體、圖示大小、Padding）能在雙欄的窄空間中依然排版整齊，不破版。

**Non-Goals (非目標):**
- 改變原有的資訊圖表動畫或資料抓取邏輯。
- 更動平板或電腦版（`sm`, `lg`, `xl` 以上）的排版。

## Decisions (技術決策)

- **Grid 類別變更**：直接將外層容器的類別由 `grid-cols-1` 修改為 `grid-cols-2`。
- **響應式字體與內距微調**：
  - 將卡片的 Padding 從原本的 `p-5` 改為響應式的 `p-3 md:p-5`。
  - 將標題文字的字體大小調整為 `text-sm md:text-[15px]` 以節省空間。
  - 將計數數字從 `text-3xl` 改為 `text-2xl md:text-3xl`。
  - 調整圖示的外層容器大小，從 `w-10 h-10` 改為 `w-8 h-8 md:w-10 md:h-10`。
- 上述調整可以確保當手機畫面切割成一半時，裡面的元件依舊有呼吸空間。

## Risks / Trade-offs (風險與權衡)

- **風險: 在極小螢幕（如 iPhone SE）上可能還是會很擠**。
  *緩解措施*: 透過將圖示與標題垂直排列（而不是原本的水平排列），或者在 Flex 排版時允許自動換行/收縮。為了維持一致性，我會先試著調整字體與圖示比例，若文字長度過長（如「農漁牧業關注」），可能會自動折成兩行，這在雙欄排版下是可接受的，只要高度保持一致（我們有設定 `h-full`）就不會影響整體視覺。
