## ADDED Requirements (新增的需求)

### Requirement: 手機版分類統計區塊為雙欄顯示
系統必須 (SHALL) 在行動裝置（小螢幕）上，將分類統計卡片以雙欄（兩欄並排）的方式呈現，取代原本的單欄排版。

#### Scenario: 行動裝置上的版面呈現
- **WHEN (當)** 使用者在手機（寬度小於 640px）上瀏覽首頁的分類統計區塊時
- **THEN (則)** 他們會看到一排顯示 2 個分類卡片。
- **AND (且)** 為了避免空間過於狹窄，卡片內部的字體大小、Padding 必須做適當的縮放（例如：標題可能需要稍微縮小，圖示也可能需要等比例調整），確保資訊在雙欄的情況下依然清晰可見且不會破版。
