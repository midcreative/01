## Why (為什麼需要這個修改)

目前的文章分類統計區塊，是使用白色底的卡片搭配簡單的資料夾圖示以及數量文字來呈現。這在視覺上缺乏吸引力，無法有效地讓這些數據引起使用者的興趣。將這個區塊升級為「資訊圖表」的風格，能讓統計數據更吸睛、更容易閱讀，也更符合現代化的網頁設計美學。

## What Changes (會有哪些改變)

- **視覺重新設計**：取代原本單調的資料夾卡片，改為色彩豐富、具有資訊圖表風格的呈現方式（例如：進度條、鮮明的色彩配置，或是類似圖表的排版）。
- **數據呈現強化**：透過更大的字體和更高的對比度，讓分類統計的數量更加突出。
- **微動畫效果**：(可選) 增加一些細微的動畫，例如當使用者滑動到該區塊時，數字會從 0 自動往上跳動到目標數量。
- **RWD 響應式排版**：確保這個資訊圖表在手機和電腦螢幕上都能完美縮放顯示。

## Capabilities (功能)

### New Capabilities (新增功能)
- `infographic-category-stats`: 使用資訊圖表風格來視覺化呈現文章分類統計，取代原本的基本卡片排版。

### Modified Capabilities (修改的功能)
- (無)

## Impact (影響範圍)

- **前端 (`index.php`)**：分類統計區塊的 HTML 與 Tailwind CSS 結構將會全面改寫。
- **CSS**：可能會需要增加新的自訂 CSS 或是 Tailwind 的類別，用來處理動畫或特定的圖表樣式。
- **JavaScript**：如果決定實作數字跳動的動畫，可能會需要一小段 JS 腳本。
- **後端與資料**：資料來源（每個分類的文章數量）完全保持不變；不需要動到任何後端或資料庫的邏輯。
