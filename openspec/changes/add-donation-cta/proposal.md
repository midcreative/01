## Why (為什麼需要這個修改)

為了方便支持者進行小額捐款，我們需要在首頁頁尾（Footer）的上方，新增一個「政治獻金」的 Call to Action (CTA) 區塊。這能提供明確的匯款資訊（銀行、戶名、帳號），並附帶一個引導捐款的按鈕，提升募款的便利性與曝光度。

## What Changes (會有哪些改變)

- **新增政治獻金 CTA 區塊**：在首頁最下方（頁尾之前）加入一個全新的區塊。
- **視覺設計**：背景使用漸層紫色設計，搭配乾淨俐落的白色卡片來呈現匯款資訊。帳號的部分將採用獨立的格子（Grid）設計，讓數字更易讀。
- **內容配置**：
  - 標題：「政治獻金開戶啦！」以及背景的裝飾文字「CARRY THE HEART」。
  - 表格：包含「銀行：004 臺灣銀行潮州分行」、「戶名：115年屏東縣議員擬參選人潘炩禕政治獻金專戶」、「帳號：088004769454」。
  - 按鈕：下方加入一顆綠色的「小額捐款 支持炩禕」按鈕。

## Capabilities (功能)

### New Capabilities (新增功能)
- `add-donation-cta`: 首頁新增政治獻金的行動呼籲（CTA）區塊。

### Modified Capabilities (修改的功能)
- (無)

## Impact (影響範圍)

- **前端 (`index.php`)**：在頁面最下方（Footer 之前）插入新的 HTML 結構。
- **CSS**：使用 Tailwind CSS 實作漸層背景與卡片樣式，不需要引入額外的外部套件。
- **資料庫**：不需要更動資料庫，這是一個純前端的視覺區塊。
