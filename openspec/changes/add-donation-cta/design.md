## Context (背景情境)

目前首頁尚未提供直接引導支持者進行政治獻金小額捐款的區塊。新增這個 CTA 區塊能有效吸引瀏覽者的目光，並直接提供完整的匯款資訊（包含銀行、戶名及帳號）。

## Goals / Non-Goals (目標與非目標)

**Goals (目標):**
- 在 `index.php` 頁尾上方加入一個全新的區塊。
- 忠實還原設計稿中的視覺風格（紫色漸層背景、白色卡片、獨立的帳號格子、綠色捐款按鈕）。
- 使用 Tailwind CSS 快速實作響應式設計（RWD）。

**Non-Goals (非目標):**
- 目前不串接任何第三方的金流 API 或線上刷卡系統。
- 不涉及後端資料庫的改動，此為靜態的展示區塊。

## Decisions (技術決策)

- **版面結構**：使用 Tailwind CSS 的 Grid / Flexbox 來排版。背景使用漸層類別（如 `bg-gradient-to-b from-[#e5eaff] to-[#7f85d2]`）。
- **獨立的帳號格子**：對於帳號數字 `088004769454`，我們會使用 PHP 或直接手寫 HTML 標籤將字串分割，為每一個數字套用獨立的邊框設計（例如 `border-r` 與等寬的 `w-8`）。
- **背景裝飾文字**：設計稿中的 "CARRY THE HEART" 將使用絕對定位 (`absolute`) 與較低的透明度 (`opacity-10` 等) 來達成浮水印的效果。

## Risks / Trade-offs (風險與權衡)

- **風險: 手機版面擁擠**：帳號共有 12 位數字，如果在小螢幕（如 iPhone SE）上，獨立格子可能會超出寬度或顯得擁擠。
  *緩解措施*: 針對小螢幕使用較小的字體大小（例如 `text-sm`）並稍微縮減格子的 padding。或者在極小螢幕時允許微幅的 X 軸滾動，但優先確保字體縮放能適應螢幕。
