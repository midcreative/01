## ADDED Requirements

### Requirement: 頂部導航欄行動版漢堡選單
系統必須 (SHALL) 在螢幕寬度小於 `1024px` (`lg` 斷點以下) 時，於頂部導航欄右側顯示漢堡選單按鈕，點擊後展開或收合包含所有主要導航項目的下拉選單。

#### Scenario: 點擊漢堡按鈕展開與切換分頁
- **WHEN** 使用者在寬度小於 `1024px` 的裝置上點擊頂部導航欄右側的漢堡按鈕
- **THEN** 系統展開 `#mobile-menu` 下拉選單，顯示「鄉鎮足跡」、「行動白皮書」、「連署實證站」與「志工招募」四個選項，且按鈕圖示切換為關閉 (`x`) 圖示
- **AND** 當使用者點擊任一分頁選項時，系統切換至對應視圖並自動收合下拉選單

### Requirement: 手機底部固定導航列 (Bottom App Bar)
系統必須 (SHALL) 在螢幕寬度小於 `1024px` (`lg` 斷點以下) 時，於畫面最下方固定顯示一排包含圖示與文字的底部導航列，方便行動裝置使用者單手快速切換主要頁面。

#### Scenario: 透過底部固定導航列切換分頁與防遮擋
- **WHEN** 使用者在寬度小於 `1024px` 的裝置上瀏覽首頁
- **THEN** 畫面底部固定顯示包含「鄉鎮足跡 (`map-pin`)」、「行動白皮書 (`book-open`)」、「連署實證站 (`shield-check`)」、「志工招募 (`users`)」四個項目的導航列
- **AND** 點擊分頁項目時，底部導航列、頂部選單與下拉選單的當前啟動項目皆同步高亮為品牌綠 (`brand-green`)
- **AND** 頁尾 (`footer`) 預留足夠的底部間距，確保滑動至頁面最底部時版權文字不會被底部導航列遮擋
